01 — The Idea

What problem does this solve?

Pakistani applicants face a 50% Schengen rejection rate. Each failed attempt costs €185+ in fees, plus preparation time, document costs, and the psychological toll of rejection. Most applicants have no idea why they got rejected — they just apply and hope. VisaScore changes that.

😤

The Problem

✗ No visibility into what embassies assess
✗ €185 non-refundable fee per application
✗ Generic rejection letters with no explanation
✗ Visa consultants charge PKR 20,000+ for vague advice
🎯

The Solution

✓ AI scores your profile across 4 key embassy criteria
✓ Know your risk before spending €185
✓ Specific, actionable fixes — not vague advice
✓ $12 — 15x cheaper than a consultant

07 — Security

Security Status

Current state before production. Green = done. Red = must fix before launch.

Done ✓

✓ API keys stored in environment variables only
✓ Webhook HMAC signature verification
✓ DB password encrypted / not in code
✓ No sensitive keys exposed to browser
✓ NEXT_PUBLIC_ prefix policy enforced

Must Fix Before Launch ⚠️

✗ CORS is currently allow_origins=["*"] — lock to your domain
✗ No rate limiting on /submit — anyone can spam Claude API calls
✗ No legal disclaimer — "not a lawyer/immigration consultant"
✗ HTTPS not enforced on webhook endpoint
